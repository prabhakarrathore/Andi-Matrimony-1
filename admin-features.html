Admin Module Features

The Admin Module provides comprehensive tools for managing the AndiMatrimony platform.

Dashboard

Provides an overview of key site statistics: new users, active users, premium members, earnings (if applicable), pending approvals.

User Management

View, search, edit, activate, deactivate, or delete user profiles. Manage user roles (e.g., free vs. premium).

Profile Moderation

Approve or reject new profiles, photos, and profile updates to maintain quality and authenticity.

Premium Plan Management

Define, create, and manage subscription plans or premium features offered to users.

Content Management

Manage static pages like About Us, Terms & Conditions, Privacy Policy, FAQs, and Success Stories.

Configuration Settings

Control general site settings, profile attributes (religion, caste, etc.), SMTP/email settings, social media links, payment gateways, Captcha, and SEO settings.

Communication Monitoring

Oversee contact messages sent through the platform's contact form or report systems.

Reporting & Analytics

View reports on user activity, earnings, registration trends, etc.

Staff / Role Management

Manage access permissions for different administrator roles if multiple staff members use the panel.
